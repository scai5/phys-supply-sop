# Nurse Scope of Practice Expansion and Physician Location

This project examines the impact of nurse scope of practice expansions on physician location. 

## Data
- Nurse SOP law classification comes from [McMichael and Markowitz (2023)](https://journals.sagepub.com/doi/full/10.1177/10775587221126777)
- Aggregate PCP supply from Area Health Resources Files
- PCP practice location identified from MD-PPAS and CMS Physician Compare
- Specialty and credentials from NPPES
- Service provision from Medicare Part B Public Use Files

## Analysis
All analysis scripts can be run from `analysis/_main.R`
